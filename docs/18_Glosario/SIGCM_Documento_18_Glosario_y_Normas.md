# DOCUMENTO 18 – Glosario, Convenciones y Normas

## Objetivo
Establecer un vocabulario común y normas de documentación para todo el proyecto SIGCM.

## Glosario
- Organización: Cliente que utiliza el sistema.
- Sede: Lugar físico donde se atienden pacientes.
- Consultorio: Espacio de atención dentro de una sede.
- Profesional: Médico u otro profesional de la salud.
- Secretaria: Usuario administrativo.
- Paciente: Persona única identificada por documento.
- Agenda: Disponibilidad del profesional.
- Turno: Reserva asociada a agenda, profesional y paciente.
- Historia Clínica: Registro longitudinal del paciente.
- Informe: Resultado de una práctica o estudio.
- Documento: Archivo vinculado a un paciente.
- Repositorio: Origen físico de los archivos.

## Convenciones
- Nombres claros y consistentes.
- Fechas en formato argentino.
- Documentos sin puntos.
- Obras sociales normalizadas.
- Auditoría obligatoria para acciones críticas.

## Estándares
- Versionado semántico.
- Documentación sincronizada con el código.
- Cambios revisados antes del despliegue.
- Seguridad por defecto.

## Cierre
Este documento sirve como referencia común para desarrolladores, analistas, QA y usuarios avanzados.
