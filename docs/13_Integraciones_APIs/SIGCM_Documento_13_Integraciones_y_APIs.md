# DOCUMENTO 13 – Integraciones y APIs

## Objetivo
Definir las integraciones presentes y futuras del SIGCM.

## Integraciones iniciales
- Supabase Auth
- PostgreSQL
- Supabase Storage
- Edge Functions
- GitHub
- Vercel

## Integraciones funcionales
- Google Drive
- OneDrive
- Dropbox
- iCloud Drive
- NAS
- Carpeta local mediante sincronizador futuro

## Comunicaciones
- Gmail
- SMTP
- Correo institucional
- WhatsApp (wa.me)
- Preparación para WhatsApp Business API

## Requisitos
Las integraciones deberán ser configurables por organización y por médico cuando corresponda.

## Seguridad
Credenciales protegidas.
Secretos fuera del frontend.
Uso de enlaces temporales cuando sea necesario.

## Evolución
Preparar conectores para calendarios, firma electrónica, receta electrónica e interoperabilidad con otros sistemas médicos.
