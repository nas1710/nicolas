# DOCUMENTO 20 – Plan Maestro de Implementación

## Objetivo
Definir el orden oficial para construir, validar, desplegar y evolucionar el SIGCM.

## Fase 1 – Estabilización
- Corrección de alta de pacientes.
- Paciente único.
- Gestión completa de usuarios.
- Login profesional.
- Navegación consistente.
- Auditoría básica.

## Fase 2 – Operación clínica
- Agenda.
- Turnera pública.
- Lista de espera.
- Historia clínica.
- Notificaciones.

## Fase 3 – Gestión documental
- Repositorios documentales.
- Bandeja inteligente.
- Envío de informes.
- Exportación institucional.

## Fase 4 – Producto SaaS
- Configuración multiempresa.
- Marca blanca.
- Dashboards.
- Estadísticas.
- Integraciones avanzadas.

## Implementación
Cada entrega deberá incluir:
- cambios React;
- SQL;
- Edge Functions;
- pruebas;
- pasos para Supabase;
- pasos para GitHub;
- pasos para Vercel.

## Producción
Antes de publicar:
- backup;
- migraciones verificadas;
- pruebas funcionales;
- validación RLS;
- validación de seguridad.

## Mejora continua
Toda nueva funcionalidad deberá actualizar la documentación, el changelog y los casos de prueba.

## Cierre
Los veinte documentos conforman la documentación funcional y técnica base del SIGCM y constituyen la referencia oficial para el desarrollo futuro del producto.
